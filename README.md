# Zomato Food Delivery App

## About the Project
The Zomato Food Delivery App is a console-based Java application developed to practise the Java Collections Framework and Object-Oriented Programming (OOP) concepts. It allows users to browse food items, register customers, place orders, calculate bills, and manage order statuses.

## Technologies Used
- Java
- Java Collections Framework
- ArrayList
- HashMap
- HashSet
- Scanner
- Eclipse IDE

## Features
- Display all available food items
- Search food items by ID or name
- Filter food items by category
- Sort food items by price
- Register and display customers
- Search customers by ID
- Place orders with multiple food items
- Calculate the total bill
- Display all orders
- Display orders by customer ID
- Update order status
- Display unique food categories
- Find the top 3 most expensive food items

## Java Collections Used
- **ArrayList:** Stores food items and order history.
- **HashMap:** Stores customers by customer ID and food items by food ID.
- **HashSet:** Stores unique food categories.

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse IDE as an existing Java project.
3. Ensure the JDK is installed and configured.
4. Open `MainZomato.java`.
5. Run the program as a Java Application.
6. Select an option from the console menu.

## Learning Objectives
This project demonstrates the practical use of Java collections, loops, conditional statements, switch cases, constructors, encapsulation, object creation, searching, sorting, and basic order management.
